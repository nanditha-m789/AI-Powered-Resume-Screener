# AI-Powered Resume Screener

An AI-powered tool that automatically screens and ranks resumes based on Job Description using Natural Language Processing.

This project helps recruiters save 70% of time by ranking candidates with a match percentage.

## 🚀 Tech Stack
- Python
- NLP, TF-IDF Vectorization
- Cosine Similarity
- PyPDF2 for PDF parsing
- Scikit-learn

## ✨ Features
- Extracts text from multiple PDF resumes
- Compares resumes with Job Description
- Ranks candidates by match score (e.g., 87.5%)
- Simple and fast
